# prog-8.github.io

Progateの練習用ページと、参考サイト・参考動画を保存しておけるブックマークアプリ「Refs」を置いているリポジトリです。

- `index.html` / `stylesheet.css` … Progate「HTML & CSS 道場」の練習ページ
- `refs/` … 参考サイト・参考動画ストック **Refs**（公開URL: `/refs/`）

## Refs の使い方

1. `refs/index.html` をブラウザで開く（GitHub Pages 公開後は `https://<ユーザー名>.github.io/refs/`）
2. URLを入力して「保存する」。タイトルを空欄にするとURLから自動で入ります
3. YouTube / Vimeo / ニコニコ動画などのURLを入れると、自動で「動画」として登録されます

### できること

- 参考サイト・参考動画の保存（タイトル・タグ・メモ付き）
- YouTubeはサムネイル、そのほかのサイトはfaviconをカード表示
- キーワード検索（タイトル・URL・メモ・タグを横断、スペース区切りでAND検索）
- 種類（サイト / 動画）・お気に入り・タグでの絞り込み、並び替え（新しい順 / 古い順 / タイトル順）
- 編集・削除・お気に入り登録
- **Gemini APIを使った自動ジャンル分け**（ジャンル・タグの自動付与）
- ジャンルでの絞り込み
- JSONでの書き出し / 読み込み（バックアップ、別端末への引っ越し）

### AIで自動ジャンル分け（Gemini API）

登録したサイト・動画を、Gemini APIでまとめてジャンル分けできます。

1. [Google AI Studio](https://aistudio.google.com/apikey) でAPIキーを発行する
2. Refs の「AIでジャンル分け」→「APIキーの設定」にキーを貼り付けて「設定を保存」
3. 「一覧を取得」でモデルを取得（一番安いFlash-Liteが自動で選ばれます）
4. 「ジャンル分けを実行」

- 分類の材料はタイトル・URL・メモ・既存タグです（ページ本文はブラウザから取得できないため読んでいません）
- ジャンル一覧は設定から自由に書き換えられます。AIはこの一覧の中からしか選びません
- 25件ずつまとめて送るので、100件でも4リクエスト程度で終わります
- 「タグも提案する」をONにすると、タグも最大3つずつ追加されます
- 結果は「元に戻す」で1回だけ取り消せます

#### APIキーの扱い

- キーは **このブラウザの localStorage にだけ** 保存されます。リポジトリには一切含まれません
- **キーをHTMLやJSに直接書いてコミットしないでください。** 公開リポジトリに載せると誰でも使えてしまいます
- Google Cloudコンソールでキーに「HTTPリファラー制限」（`https://<ユーザー名>.github.io/*`）をかけておくと、他サイトからの悪用を防げます
- それでもブラウザの開発者ツールを開けば自分のキーは見えます。他人に配るサイトにする場合は、Cloudflare WorkersなどにAPIキーを置いた中継サーバーを立てて、そこ経由で呼ぶ構成が必要です

### データの保存先

サーバーを使わず、ブラウザの **localStorage** に保存しています。そのため

- 同じブラウザで開けばデータは残ります
- 別の端末・別のブラウザ・シークレットウィンドウには引き継がれません
- ブラウザのデータを消すと一緒に消えます

大事なデータは「書き出し」でJSONを保存しておいてください。別端末では「読み込み」で復元できます（同じURLのものはスキップされます）。

### 技術メモ

外部ライブラリなしのHTML / CSS / JavaScript（バニラJS）だけで作っています。

- `refs/app.js` … UI・データ管理
- `refs/gemini.js` … Gemini APIクライアント（モデル一覧取得・分類）

サムネイルは `img.youtube.com` と Google の favicon サービスを利用し、取得できない場合はタイトルの頭文字タイルを表示します。

ジャンル分けは Gemini の [構造化出力](https://ai.google.dev/gemini-api/docs/structured-output)（`responseSchema` + `enum`）を使い、必ずジャンル一覧の中から選ばれるようにしています。モデルIDは更新が早いため固定せず、`ListModels` で取得した一覧から選ぶ方式です。
